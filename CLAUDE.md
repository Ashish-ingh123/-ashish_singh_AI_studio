# Portfolio website

Personal portfolio site for Ashish Singh, Software Engineer (full-stack: C#, .NET, SQL Server,
React; AI integration with RAG and LLMs). Purpose: present Ashish as an experienced developer
who is available for projects, with the services he offers, his experience, skills, projects,
education and certifications, and make it easy to reach him by phone, email, LinkedIn or
GitHub. Deploy target: Vercel.

## Stack (fixed)

Do not change the stack or add any other package without asking first.

- Next.js, latest stable, App Router, with TypeScript in strict mode
- Tailwind CSS
- Motion (`motion/react`) for animation
- next-themes for light and dark mode
- lucide-react for icons
- @google/genai, Google's Gemini SDK, used only by the server route src/app/api/ask (the
  owner approved this one package on 2026-11-17 for "Ask about Ashish")
- npm as the package manager, deployed on Vercel

## Rules

1. All site content lives in one typed file: `src/content/profile.ts`. Components render
   from that object. No text, link or date is hard-coded anywhere else.
2. Mobile-first responsive layout: design for a phone width first, then widen.
3. Accessible: everything works with the keyboard, focus rings stay visible, every image has
   alt text, and `prefers-reduced-motion` is respected (animations are reduced or removed).
4. Lighthouse score of 95 or higher in every category.
5. The mobile number is shown only in the Contact section, from `profile.links.phone` (the
   owner asked for it on 2026-11-05). Do not repeat it in the header, hero, footer, metadata
   or structured data.
6. Plan first and wait for approval before each step.
7. Explain concepts simply. The owner knows React and C#; relate new ideas to those.
8. Positioning: the title is "Software Engineer", never "Backend". No college-level content:
   no school marks, no CGPA, no school or college achievements, and no resume download. Every
   claim on the site must be real; never invent experience, projects, clients or numbers.

- Live terminals: the terminal window beside a project types its lines out, once when half of them have scrolled into view and again whenever the Replay button in its title bar is pressed. project-visual.tsx stays on the server (the glow, and the padding that keeps the text clear of the description card); terminal-window.tsx is the client part. The server renders every line in full and the text never leaves the page: letters still to come, and the prompt marks of lines not yet reached, only get the class terminal-waiting (opacity 0, in projects.css). They keep their place, so nothing shifts or wraps differently while a line fills in, and screen readers still read the whole line; visibility: hidden would have taken the text away from them, and a transparent colour would have tripped the contrast audit. There is one piece of state, ticks: null shows everything, a number is how many ticks of the pass have gone by. A tick is 14ms and types one letter, and the cursor waits 12 ticks at the start of each line; with more text the ticks get shorter, so a pass never takes longer than 2.8 seconds (MAX_MS), well inside the five-second limit for motion without a pause control. The count is read from the clock inside requestAnimationFrame, so it stops with a hidden tab and a slow frame makes the typing jump ahead instead of falling behind. The cursor is a block one letter wide, position: absolute with no left or top, which leaves it at the spot it would have had in the line while it takes up no room there. A window that is already partly on screen when the page loads (a reload, coming back from the case study) is left as it is, because emptying it would make words vanish in front of the visitor; one that is off screen is emptied at once and types when it arrives. Under reduced motion the state stays null and CSS hides Replay. The Replay button is 32px tall in a bar 36px tall (a negative margin hides the difference), and its focus ring sits on its edge (outline-offset 0), because the window cuts off whatever sticks out of it. A print rule shows waiting text in full.
